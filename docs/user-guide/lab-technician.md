# Lab Technician guide

You enter results for tests doctors have ordered.

## The lab worklist

**Lab** is your home page. It shows how many tests are **Waiting for a result**, how many were **Resulted today**, and how many were **Critical today**. It refreshes every minute.

Tests appear under **Waiting for a result** as soon as a doctor orders them, oldest first, with the doctor's **Note for the lab**.

## Entering a result

1. Click **Enter result** next to the test.
2. Each parameter of the test is listed with this patient's reference range. Enter the numbers without units; **Low**, **High** or **Critical** appears as you type. Leave blank anything not done.
3. To report something that isn't listed, click **Add parameter** and fill in its name, result, unit and range. It is for this patient only. If you type a range such as `10 - 20`, a value outside it is flagged for you. Otherwise choose the flag yourself.
4. Add **Notes** if needed and click **Save result**.
5. Click **Print report**. It includes any documents you attached.

A test with no parameter list starts with one row for the test itself. If a yellow note says there is no reference range, the patient's age or sex is probably not recorded, so nothing is flagged for you. Tell the doctor about any concerning value.

Your clinic admin can add a parameter to a test permanently, so you don't have to add it each time.

## Attaching a document

Under **Supporting documents**, choose a machine printout, scanned report or photo, or drop it on the box. Use PDF, JPG or PNG, up to 10 MB each. You can do this before or after saving the result, and what you have typed stays on the page.

- **The whole result is in a document** (for example, from an outside lab): attach it, leave the parameters blank, choose the **Interpretation** and click **Save result**.
- **It arrives later:** open the test from **Resulted today** or the patient's **History**. The result goes back to the doctor as unread.
- **Wrong file:** click **Remove** and give a reason. It leaves the patient's record and the report, but a record of it stays.

Documents show in the patient's record for the doctor and print with the report.

Under **Resulted today**, click a test's name to open it. **Report** opens the printable report and **History** shows the patient's results over time.

The result appears in the doctor's **Unread results** straight away. For a critical result, also tell the doctor in person or by phone. NuvaLyf does not replace that call.

Saved results cannot be edited. If you made a mistake, tell the doctor so they can record an amendment.
